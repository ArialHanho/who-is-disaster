# 관리

## 버전과 업데이트

현재 공개 버전은 **0.3.0**입니다. 앱 버전의 기준은 `agent_app/__init__.py`입니다. 설치형은 새 설치 파일로 덮어 설치하고, 소스형은 변경 사항을 보관한 뒤 `git pull --ff-only`와 의존성 설치를 실행합니다.

기존 설치본의 데이터와 자동 실행을 유지하기 위해 내부 실행 파일·데이터 폴더·Windows 등록 이름은 `CodeCompanion`을 유지합니다. 사용자에게 보이는 제품명은 **Who is disaster**입니다.

## 데이터와 백업

| 형태 | 사용자 데이터 |
|---|---|
| 설치형 | `%LOCALAPPDATA%\CodeCompanion\.data` |
| 소스형 | 저장소의 `.data` |
| 별도 위치 | `CODE_COMPANION_HOME`으로 지정한 폴더 안의 `.data` |

백업할 때는 트레이에서 앱을 종료한 뒤 `.data` 전체를 다른 개인 폴더에 복사하세요. 저장소 연결, 문제 이력, 캐릭터 팩, 위치와 대화 설정이 포함됩니다. 설치 파일에는 이 데이터가 포함되지 않습니다. 백업을 공개 저장소나 Issue에 첨부하지 마세요.

로그는 설치형의 `.data/logs/desktop.log`에 남습니다. 보고할 때는 개인 경로·저장소 코드·계정 정보가 섞이지 않았는지 확인하고 필요한 오류 부분만 공유하세요.

## 문제 해결

- **AI 연결이 안 됨**: `codex login status`, CLI 설치 경로, 구독 한도를 확인합니다. 필요한 경우 `CODEX_EXECUTABLE` 환경변수로 실행 파일을 지정합니다.
- **Git을 못 찾음**: Git 2.38 이상을 설치하고 앱을 다시 시작합니다.
- **저장소가 안 보임**: GitHub CLI 로그인 계정과 조직 접근 권한을 확인합니다.
- **전체 검토 미완료**: 완료한 묶음 수와 오류를 확인한 뒤 다시 분석합니다. 큰 저장소는 요청 수와 구독 사용량이 늘어납니다.
- **캐릭터가 안 보임**: 트레이의 비서 다시 열기 또는 가장자리 탭을 사용합니다. 마지막 수단으로 앱을 종료한 뒤 `.data/widget.json`만 백업해 이름을 바꾸면 다음 실행 때 위치를 다시 잡습니다.
- **글자·말풍선**: 포함된 Jua 폰트가 없거나 깨졌으면 같은 버전을 다시 설치합니다. 사용자 이미지의 투명 여백이 과도하면 제작 안내에 따라 줄입니다.

Windows 자동 실행은 앱 설정에서 끄고 켤 수 있습니다. 앱 제거는 사용자 데이터를 자동 삭제하지 않습니다.
